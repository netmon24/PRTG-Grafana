# Sicherheitsmeldungen

Bitte melden Sie Sicherheitslücken **nicht** als öffentliches Issue.

Nutzen Sie auf GitHub den Reiter **Security** und dort „Report a vulnerability“ (privates Melden). Beschreiben Sie, was Sie gefunden haben, wie man es nachstellt und welche Version betroffen ist. Zugangsdaten, API-Keys und echte Hostnamen gehören nicht in die Meldung.

Unterstützt wird jeweils die neueste veröffentlichte Version (`ghcr.io/netmon24/prtg-grafana`).

Hinweise zum sicheren Betrieb (TLS, Zugriff auf Portal und InfluxDB, Geheimnisse in der `.env`) stehen in `docs/ausrollen.md`.
